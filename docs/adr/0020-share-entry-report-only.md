# 分享入口只留报告；周期放开月报与自选区间

ADR 0015 把报告钉成已结束自然周期，并写「薄切版界面只暴露周报、本期不交付月报」。ADR 0018 把分享对话框收成「周报 | 额度」两种卡片。随后产品把额度卡从分享入口拿掉，并让用户选一周、一个月或自选闭区间。0015 的周期入口、0018 的卡片种类，都被证伪。

**本 ADR 不改 ADR 0015 / 0016 / 0018 / 0019 原文。** 口径禁令仍然有效：报告只读消耗记录；洞察在 Rust；海报 CSS 不复用主样式表；数字禁止把官方额度、代码量、Cursor 账号用量并进报告。被取代的只是入口、卡片种类与周期寻址。

**决定**：

1. **分享对话框只出报告。** 官方额度卡不再是产品入口。官方额度仍在总览与托盘。不要为分享再做一张额度卡，也不要把额度百分比画进报告海报。
2. **界面周期是一周 / 一个月 / 区间。** `ReportPeriod.kind` 为 `week` | `month` | `custom`。
3. **week / month 仍只寻址已结束的完整自然周期**（`offset = 0` 是最近一个已结束周期，进行中的不可选）。**custom 是闭区间** `from` / `to`（`YYYY-MM-DD`，含起止日）：可选到今天，不可选未来，最长 93 天。

## 被证伪的几条

**「薄切版界面只暴露周报，本期不交付月报」（0015）。** 对话框分段是一周 / 一个月 / 区间。kicker 随 `kind`：`码表 · 周报` / `码表 · 月报` / `码表 · 区间`。单位对应「本周 token」/「本月 token」/「区间 token」。

**「分享对话框左侧第一项是卡片类型：周报 | 额度」（0018）。** 额度卡组件、CSS、view model 已删除。本机偏好只记海报风格 id；旧字段 `kind` / `quotaProvider` 仍可读，不记周期 offset。

**「按天柱固定七根、标签一到日」（0015 槽位 7）。** 按天序列覆盖周期内每一个本地日历日，零也是 0。周报仍七根、标签「一…日」；月报与区间用日号，超过 10 天走密柱。单日 custom 就是一根柱，不再补六根空柱。

**「已结束的完整自然周期」是唯一可寻址范围（0015）。** custom 不是自然周期，且可以含今天。

## 仍然有效

- 七个槽位种类不变（总量、深夜/活跃、最忙一天、来源占比、模型 Top、最贵/最多一次、按天柱）。空模型名与「（未标注）」跳过，仍按 0015 后补。
- `has_data = false` 不渲染海报、不写「暂无数据」。
- 最贵一次若带项目，只显示路径最后一段（目录名），不写整段 cwd。
- 周报风格注册表（0019）只服务报告海报。0016 / 0019 里「并入额度卡 CSS」以本篇为准：额度卡 CSS 已不存在，门禁只覆盖 `posterStyleRegistry` 与 spike 夹具。
- 0018「数字禁止跨卡片合并」仍有效。当前只有一种卡片，所以这条表现为：禁止把官方额度写进 `ReportDto` 或海报。以后若加回第二种卡片，必须先改本篇的卡片名单。

## 本轮落地

- `ReportPeriodKind::Custom` + `from` / `to`；前后端都钉 `CUSTOM_PERIOD_MAX_DAYS = 93`。
- `ReportDialog` 周期分段；`reportCopy` 按 `kind` 换 kicker / 单位 / 空态说明。
- 删除 `QuotaPoster.tsx`、`quotaPoster.css`、`quotaCard.ts`、`useShareQuota.ts` 等额度卡分享通路。
- `sharePreference` 只暴露 `posterStyleId`；序列化仍写 `kind: "week"`、`quotaProvider: null`，避免旧结构读失败。

## Consequences

- 读到 0015「只暴露周报」、0018「周报 | 额度」、0016 / 0019「额度卡海报」时，以本 ADR 为准。
- 报告口径、洞察、风格注册表仍对照 0015 / 0019。
- 不要把官方额度卡加回分享入口，除非先改本篇。
- 测试缝：`reportPeriod`、`reportCopy` 周期文案、Rust `report` 的 week / month / custom 解析。海报 DOM / 截图仍不在 CI。
