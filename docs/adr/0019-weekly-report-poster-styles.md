# 周报海报内置风格

ADR 0015 把周报钉成七个固定槽位、只读消耗记录；ADR 0018 把分享对话框收成周报与官方额度卡两种卡片。两篇都把「周报视觉皮肤 / 第二种周报版式」列进明确不做，是为了挡住模板市场和口径漂移，不是为了永远只留一张深色 dashboard。

用户已经能从总览分享周报，但只有一种固定视觉。分享场景变多之后，单一皮肤容易审美疲劳，也无法覆盖浅色磨砂、紫蓝玻璃、赛博霓虹等不同表达。若为了「更好看」把环比、日均、第几周、官方额度剩余或代码量画进海报，0015 的口径就假了；若做成用户上传 CSS / 网络风格包，0018「不是模板」也会塌。

**决定**：周报分享增加开发者维护的**内置风格注册表**。风格只改视觉层。所有风格消费同一份海报 view model，展示同样七个槽位和同样数字。官方额度卡保持单风格，不进注册表。

本篇取代 0015 / 0018 里「不做周报视觉皮肤、第二种周报版式、周报海报跟随应用主题、以及周报 CSS 一律禁止玻璃 / 霓虹效果」这些非目标。它不取代报告口径、洞察规则、周期语义，也不取代额度卡边界。

## 领域词汇

不新增数据维度。风格不是卡片种类，也不是模板。

**周报海报风格**：同一份 `PosterViewModel` 的一种内置视觉实现，含稳定 id、面向用户的名称、选择器色块元数据、以及渲染组件。可以有独立布局、独立 CSS、独立装饰。不能新增取数通道。

不要把风格叫成「模板」或「皮肤包」。不要把风格注册表做成卡片种类注册表——卡片种类仍只由 ADR 0018 的封闭名单扩展。

## 约束一：只动视觉，不动口径

报告 DTO、Rust 报告聚合、洞察规则、周期逻辑、七槽位契约不变。风格不得增加真实数据字段，包括但不限于：环比、日均消耗、第几周、官方额度剩余、代码量、Cursor 账号用量、对话指标。

设计稿里若出现上述数字，只当视觉参考，不得变成报告数据。

## 约束二：注册表由开发者维护，不是运行时插件

每个已注册风格有：

- 稳定 id（kebab-case，写入本机偏好后必须还能对上）
- 面向用户的名称
- 选择器色块元数据（固定色板，不跟随应用主题）
- 渲染组件（`PosterViewModel` → 海报 DOM）

首批内置 id：`dark-analytics`、`light-glass`、`purple-glass`、`cyber-neon`。`dark-analytics` 是默认风格，并收编当前周报海报视觉；没有并行的遗留第五套。

未知、缺省或损坏的风格 id 回退 `dark-analytics`。用户不能上传模板、编辑 CSS、安装风格或从网络拉取风格包。装饰资源必须是纯 CSS、inline SVG 或打包进包内的 data URI；外链图片在 `foreignObject` 截图里不可靠。

实现入口是前端 `posterStyleRegistry`。分享对话框按 id 解析组件，不要按风格名在对话框里铺分支。

## 约束三：截图路线与额度卡不变

现有截图与剪贴板机制保持不变：独立海报 DOM、`foreignObject` 捕获、逻辑宽度 720px、导出 2×、PNG 写入系统剪贴板、不落盘。不新增 Tauri command。

官方额度卡仍是单风格，不展示风格选择器，不读风格偏好。周报与额度卡的数字仍然禁止合并。

## 偏好与选择器

选中的风格 id 走现有分享偏好存储，只留在本机 webview，不进备份。选择器只出现在周报分支，复制进行中与卡片类型 / 周期 / 账号一样锁定。空周期、加载中、失败态保持原样，选了风格也不能复制空海报。

本篇记录产品决定。选择器 UI 与后三个风格的落地可以分票，但必须挂在同一张注册表上，不能再开一套遗留海报。

## CSS 隔离

海报 CSS 仍与应用外壳隔离：不得 `@import` 主样式表，不得复用应用主样式规则，不得依赖运行时外链资源。周报风格可以使用 `color-mix` 与 `backdrop-filter` 做玻璃 / 霓虹；额度卡 CSS 仍按 0018 禁止这两项，直到有单独决定改它。

门禁由 `src/report/posterCss.test.ts` 盯隔离与主样式复用，覆盖清单从 `posterStyleRegistry` 推导（每个已注册风格必须带可解析的 `stylesheet`，并由渲染件实际 import），并并入额度卡 CSS。不得另维护一份会漏掉新风格的手写文件列表。不在 CI 里做像素快照。

玻璃与霓虹的保真度靠本机 spike 与打包后的 Tauri WKWebView 目视，**每种已注册周报风格都要过一遍**：

1. 浏览器打开 `http://localhost:1420/report-spike.html`（`pnpm dev`）。页上会列出全部已注册风格；用同一份假数据并排对照，再用风格开关对当前风格点「截图」，核对屏上渲染与 foreignObject PNG。`?case=single-night` / `?case=single-day` 把极端七槽位夹具铺成全部风格。
2. 打包后的 Tauri 窗口（WKWebView）里打开分享对话框，对每种周报风格各复制一次，粘贴到预览应用：中文、玻璃模糊、霓虹发光、透明圆角、inline 装饰、按天柱、来源条，以及剪贴板图与预览一致。额度卡仍按 0018 做深浅主题目视，不走风格选择器。

仓内复跑入口仍是 `docs/spikes/report-poster/NOTES.md`。

## 明确不做

用户自建模板、模板市场、运行时风格插件、上传或在线编辑 CSS、下载风格包。给官方额度卡套多风格。改报告聚合、洞察规则、周期语义或费用优先级。为分享新开 Tauri command。保存 PNG、导出 PDF、水印、报告历史留档、定时生成。CI 像素快照。

## Consequences

- 当前海报成为 `dark-analytics`，预览与复制对现有用户保持同一张图，直到他们主动换风格。
- 后续内置风格只往注册表加一行，并继续消费 `toPosterViewModel` 的输出。
- ADR 0015 仍管报告数字与洞察；ADR 0018 仍管卡片种类与额度卡。本篇只放开周报视觉层。
- 测试缝：注册表完整性（id 唯一、默认存在、名称与色块合法、stylesheet 可解析、渲染件可解析）、偏好解析回退、海报 CSS 隔离（覆盖面从注册表推导；周报允许 `color-mix` / `backdrop-filter`，额度卡仍禁）。报告 view model 与额度卡用例保持原缝，不在本篇重测口径。
