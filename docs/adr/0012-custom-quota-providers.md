# 自定义额度提供商

内置的 9 个官方额度账号之外，用户还在用第三方 API 中转站和聚合服务：OpenAI 兼容中转、自建的 NewAPI / OneAPI 站点、OpenRouter、DeepSeek 等。这些普遍是充值制，比订阅制**更容易毫无预警地断掉**——而「官方额度」区块只认写死的那 9 家，恰好漏掉了最容易断的那条。

**决定**：新增「自定义提供商 (Custom Quota Provider)」——用户在设置页自行登记、按**内置预设类型**取数的账号级额度来源。它属于「官方额度」维度，与消耗记录、本机 5 小时 / 7 天估计窗、Cursor 账号用量、代码量互不相干，不进本机 token KPI。

## 边界

这是 ADR 0008 之后的又一条受控联网通道，且是第一条**目标地址由用户提供**的通道。因此边界必须写死：

- **只允许内置预设类型**。解析器是编译进应用的，用户只选类型、不填 JSON 指针。理由有二：报错能写成人话（「用量接口里没有 total_usage」而不是「指针 /data/quota 找不到」），用户也不需要读接口文档。
- **只打计费 / 余额接口**。不下发模型调用，不拉取会话，不摄取任何正文。
- **不进消耗记录**、不进 `UsageRecord` / `Source`、不进本机 token KPI、不进 5 小时 / 7 天估计窗、不进代码量与趋势明细。
- **凭证不进备份**。配置（名称 / 类型 / 地址 / 开关）与密钥分两份文件存；备份目录是设计成给人整个拷走的，密钥进去等于每次备份都在扩散凭证。

## 架构：平行通道

内置 9 家的 `OfficialQuotaProvider` 枚举及其穷尽匹配**一行不改**——它们的编译期穷尽保障不因这个功能被削弱。自定义提供商走一条平行通道，两边各自产出额度行：

- **合流点**：`official_quota::load_dto`，内置行之后追加启用的自定义行。这是整个应用（首页、托盘、告警）取用额度数据的唯一出口，合流放这里意味着下游零改动。
- **取数**：并入现有的作用域线程池 `fetch_in_parallel`，与内置各家同一波并发，不新增调度机制。两侧共用 `QuotaTarget`（标识 + 展示名）这一个形状。
- **退避与告警**：退避状态的映射键、告警去重键的 provider 字段本来就是字符串，天然兼容，状态文件格式不变、无需迁移。
- **托盘最紧一档**：`tightest_window` 跳过 `custom:` 前缀。「最紧」的语义是「最快撞线、撞了会自己重置」；充值制余额是存量不是流量，不充值就永远不回落，一条长期 95% 的余额会把托盘标题钉死，把每天真正在动的 5 小时窗挤掉。

## 标识与命名

标识随机生成、带 `custom:` 前缀（形如 `custom:a3f9c1`）。前缀同时承担三个职责：与内置 9 家永不冲突、作为托盘「最紧一档」的跳过判据、界面上一眼分辨自定义与内置。

名称是纯展示标签，可改可重复；**改名不改标识**——额度缓存、退避状态、告警去重记录全部跟着标识走。

## Consequences

- `OfficialQuotaWindow` 增加三个可选金额字段（已用金额、上限金额、币种），允许「只有百分比 / 百分比 + 金额 / 只有金额」三种形态并存。新增字段全是 `Option`，旧缓存不需要迁移（有独立测试盯着这条）。
- 请求地址归一化只在 Rust 存在一份：剥掉结尾斜杠与结尾的 `/v1`，再按预设类型拼接接口路径。前端不重写，否则界面上写的和真正请求的会各自漂移。
- 预设类型枚举一次性定义齐 6 种（OpenAI 兼容计费 / NewAPI-OneAPI / OpenRouter / DeepSeek / 硅基流动 / Moonshot），避免后续补齐时再动枚举。首版只实现 OpenAI 兼容计费，其余在取数入口给出「暂未支持」的人话错误，不 panic。
- 解析接缝按预设类型分派、**只有一个入口**。后续补齐其余 5 种时接缝数不增长，新解析器直接复用同一个测试入口。
- 恢复备份后配置在、密钥为空。该行显示「未配置密钥，请在设置页重新填写」——这是待办提示，不是取数失败。
- 取数失败沿用「最后一次正确结果」：保留上次窗口，只更新错误文案，且错误必须是人话（密钥失效 / 地址不对 / 网络不通），不是裸的 HTTP 状态码。
- 自定义提供商**不进**首页「配置显示」面板。该面板管的是「画不画」，而自定义提供商的开关管的是「取不取数」，语义不同；两处都放会变成两个互相打架的开关。
- 首版实现的 OpenAI 兼容计费解析器**照公开接口写、用 fixture 测**，未经真实中转站账号验证。「测试通过」不等于「验证过」。
