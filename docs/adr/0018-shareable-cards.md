# 可分享卡片

ADR 0015 把「发出一张图」钉成报告：已结束自然周、只读消耗记录、七个固定槽位。用户还想发另一件事——这家账号现在还剩多少官方额度。两条错路几乎必然会来：把额度百分比画进周报，让「报告只读消耗记录」变假；或把入口做成模板市场，让皮肤、版式、口径乘在一起。

现有 ADR 没有一篇把「可转发的图」从「报告」里拆出来。0015 管报告的口径与洞察；0008 / 0012 管官方额度怎么取、怎么过期、怎么估计撞线；0010 管落盘。谁都可以复制位图这件事，还没有一个名字。

**决定**：新增领域产物「可分享卡片 (Share Card)」。它不是独立数据维度，也不写入消耗记录。报告是其中一种卡片。薄切版再加一种：**官方额度卡**。两种卡片共用截图路线和系统剪贴板，**数字禁止跨卡片合并**。

不要把卡片类型叫做「模板」。薄切版没有皮肤、没有用户自建模板、没有画廊。下文「薄切版」均指这个范围，不是又一个领域词。

## 领域词汇

**可分享卡片 (Share Card)**：一张为转发而排版的图，只写系统剪贴板，不落盘。每一种卡片只读一个已有维度，自己处理空态。它不是 token KPI，不是仪表盘截图，也不是报告的别名。

**官方额度卡**：以一家官方额度账号（含用户登记的自定义提供商）为对象的可分享卡片。读官方额度维度，不读消耗记录。

**报告 (Report)**：含义仍只由 ADR 0015 定义。某个已结束自然周期内、仅基于消耗记录的可分享汇总。本篇不扩大报告的口径、不改七个槽位、不把洞察规则挪出 Rust。

不要把可分享卡片叫成「模板」或「导出」。导出是表格 CSV / 图表 PNG / 对话正文（0015 的边界表）。不要把额度卡叫成「报告」——报告不读官方额度。

## 约束一：数字禁止跨卡片合并

周报的 token 与费用仍然只来自消耗记录，禁令与 0015 相同。

官方额度卡的百分比、金额、重置时间、预计撞线只来自官方额度那一行。禁止把消耗记录、本机 5 小时 / 7 天估计窗、代码量、Cursor 账号用量画上去，更不得折成 token 或并进周报柱状。

以后若加第三种卡片（代码量等），必须是新的卡片类型、自己的空态、自己的口径标签。禁止在一张图上混拼多个维度，也禁止把新维度塞进 `ReportDto`。

看到有人把官方额度百分比画进周报进度条，或把周报 token 写在额度卡大数字上，就是在违反本 ADR，不是「让海报更完整」。

## 约束二：不新开取数通道，webview 不算数

官方额度的唯一出口仍是 `official_quota::load_dto`（ADR 0008 / 0012）。分享对话框自己调用现有的 `get_official_quota` 与 `refresh_official_quota`，不吃总览内存里那份 DTO，也不为海报再开第三条通道。

webview 把**一行**官方额度记录映射成海报文案与排版。它不算窗口百分比、不算撞线、不自己定义过期阈值。过期阈值、撞线估计、窗口列表仍以官方额度模块为准。改一句海报措辞不必重编 Rust；改「何时算过期 / 何时估计打满」必须走 0008，不能写在卡片组件里。

报告侧不变：洞察仍在 Rust `report` 模块，一次 `get_report` 返回整份 DTO（0015）。

归一化输出未变，`ADAPTER_VERSION` 不递增。不新增 Tauri command。

## 产品入口

总览入口文案是「分享」，不再叫「生成周报」。一个对话框，左侧第一项是卡片类型分段控件：周报 | 额度。

次级选择互斥，不要并排：

- 周报：现有周期导航（更早一周 / 更近一周）。打开对话框时 `offset = 0`。同一次打开内切走再切回，可保留本次 offset；该 offset **不**写入持久化。
- 额度：账号列表。只列出**可见且有快照**的行。隐藏账号（`hidden_providers`）与主窗口「配置显示」一致。`unavailable`、从未拍到的行不进选择器。列表顺序与官方额度 DTO 行顺序一致（内置在前，自定义按其登记顺序）。

只有一家合格账号时可以不展示账号选择器。合格账号一家都没有时，停在额度类型，说明原因，禁用复制，不渲染海报——不要静默切回周报。

记住卡片类型与额度账号 id，走本机 webview 存储，**不进备份**。损坏或缺字段时默认周报。记住的账号已隐藏、消失或没有快照时，落到当前第一家合格账号。

## 官方额度卡：谁上图

一张额度卡 = 用户选中的那一家账号的**全部窗口**。Cursor 一档里并行的总量 / Auto / API / 按需画在同一张图上。自定义提供商未隐藏且有快照时可以出卡。

不是托盘的「最紧一扇」（那是瞄一眼）。不是设置里可见的全部账号叠在一张图上（那是把额度面板截下来）。

## 官方额度卡：固定槽位

薄切版固定这些槽位，全部只依赖这一行官方额度记录：

| # | 槽位 | 规则 |
|---|------|------|
| 1 | 品牌行 | 固定「码表 · 额度」 |
| 2 | 账号 | 展示名；有套餐则写套餐 |
| 3 | 窗口 | 该账号全部窗口。标签 + 百分比和/或金额口径（有什么画什么）。前端不把金额折成 token，不把百分比折成金额 |
| 4 | 重置 | 该窗有重置时间则写；没有整段省略 |
| 5 | 预计撞线 | 见下一节 |
| 6 | 快照时间 | 绝对时刻，文案「数据截至 {clock}」。禁止相对时间（「3 分钟前」）。接收方稍后打开聊天记录时，「3 分钟前」是错的 |

error、todo、内部 `kind`、未检测到的其它账号，都不进海报。缺字段整段省略，不写「—」「暂无数据」「暂无估计」。金额 / 百分比 / 重置 / 撞线措辞复用现有官方额度展示函数，不新发明数字格式。时钟用绝对格式化，不用会输出破折号占位符的空值分支。

## 新鲜度与预计撞线

新鲜度三态仍是 0008 的 `official` / `stale` / `unavailable`。告警在 `stale` 时不弹，本篇不改告警。

| 新鲜度 | 出图 | 快照时间 | 预计撞线 |
|--------|------|----------|----------|
| `official` | 可复制 | 必须印 | 该窗已有估计则印，没有则整段省略 |
| `stale` | 可复制 | 必须印 | **整段省略** |
| `unavailable` | 不出图、不复制 | — | — |

预计撞线不是官方字段，是最近两次官方快照的本地估计（0008）。应用内文案已经写明「不是官方给出的时间」。海报上必须看得出这是估计；措辞与额度面板相同：「预计 … 撞线」「已打满」「本窗估计打不满」。

过期快照仍可复制「拍到时用了多少」，但不得把失效的 ETA 印出去。两拍不够、抖动、间隔不足、超出估计窗口：与面板一样没有估计，海报整段省略，不写占位。

取数失败不覆盖旧窗口（0008）。有旧窗口就按实际新鲜度出图；错误文案留在对话框，不进 PNG。

## 取数时序

切到额度（含打开时默认就是额度）：先画缓存，再后台刷新。同一次对话框打开内从周报切回额度，不重复刷新。

复制进行中：忽略迟到的刷新；禁止切换类型、周期、账号；禁止再次复制。刷新失败停在缓存，按上一节规则决定能不能复制、印不印撞线。

不要把打开对话框堵在 Codex app-server / Cursor / Grok 的网络上。

## 渲染与输出

两种卡片都是独立 DOM、独立受限 CSS，不是现有界面的快照。截图走 `modern-screenshot` 的 `foreignObject` 路线（0015 的 #150 已 GO）。逻辑宽度 720px，高度随槽位撑开，导出 2×，用户不可调。禁止 `color-mix` 与 `backdrop-filter`，不得 `@import` 或复用应用主样式表。海报里不用 ECharts。跟随应用当前主题；薄切版只保证当前主题下正确，改卡片要出深浅两张图人工看。截图光栅化无法在 CI 里做像素断言。

薄切版不加半透明水印、不加角标 logo。周报品牌行仍是「码表 · 周报」；额度卡是「码表 · 额度」。

只写系统剪贴板，不落盘，因此不触发 ADR 0010。若将来补「保存 PNG」，必须先把落盘收编进 `user_files` 唯一入口，禁止再加一处裸写——周报与额度卡同一条禁令。

额度卡不需要再做一次截图 spike。本机接到真实窗口时对额度卡做一次深浅主题目视即可。

## 与报告、导出的边界

| 通路 | 产物 | 读什么 | 写用户文件 |
|------|------|--------|------------|
| 报告 | 一张叙事周报 | 消耗记录，已结束自然周 | 只写剪贴板 |
| 官方额度卡 | 一张账号额度图 | 一家官方额度账号的当前窗口 | 只写剪贴板 |
| 表格 CSV / JSON、图表 PNG、对话导出 | 仍按 0015 | 当前视图 / 单条会话 | 仍按 0015 / 0010 |

可分享卡片不是「把现有导出拼成一张长图」，也不是额度面板的缩略图。周报不替代额度卡，额度卡也不长出第二人称 token 评语。

## 明确不做

周报视觉皮肤、第二种周报版式、用户自建模板、模板画廊。代码量卡、Cursor 账号用量卡、会话卡、对话记录卡、把多个维度混拼成一张图。额度卡上画多家账号。自动选择最紧的一扇窗作为海报内容。把预计撞线印在过期快照上。保存 PNG、PDF、水印、历史卡片留档、定时生成。为分享新开官方额度取数通道。改 ADR 0015 的报告口径与七槽位。月报交付。

## Consequences

- 总览入口与对话框壳子由本篇收编。报告的周期、洞察、七槽位仍只对照 0015。
- 额度卡测试缝是前端纯函数：一行官方额度记录 + 当前时刻 → 能否出图、槽位是否出现、过期是否去掉撞线、账号回退落到谁。CSS 禁令挂在现有海报子集用例上。海报 DOM、截图、剪贴板、刷新时序在 CI 里不测。
- 官方额度模块的新鲜度、撞线、合流点不变。分享只是又一个只读消费者。
- 改卡片种类要先改本篇的封闭名单，不要先做可插拔注册表。
