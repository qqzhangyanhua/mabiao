# 报告海报可另开 Cursor 账号用量分区

ADR 0015 把报告钉成只读消耗记录，并写「薄切版里代码量 / 官方额度 / Cursor 账号用量干脆不出现」。用户在概览能看见 Cursor 账号用量，分享海报却没有，会以为漏数。把账号用量并进七个槽位会污染本机 token 口径，单独做第三种卡片又让「生成一张周报」仍缺这块。

**决定**：报告海报可以附一块「Cursor 账号用量」分区。数字来自当期 Cursor 账号用量缓存，时间窗与报告周期对齐。禁止把该分区并进七个槽位的总量、按天、来源占比、模型排行、时段洞察或最贵会话。`has_data` 仍只看消耗记录条数。代码量与官方额度仍不出现。

这是 0015「以后若要附，必须另开分区、另标口径」的落地，也修订 0018「禁止把新维度塞进 ReportDto」：`ReportDto.cursor_account` 是唯一允许的附加字段，只服务这一块分区。0020「数字禁止把 Cursor 账号用量并进报告」仍指并进七个槽位，不禁止这块分区。

不要把 Cursor 账号用量画进来源占比条，也不要因为只有账号用量、没有消耗记录就出海报。
